1. Реалізація та дослідження шифру моноалфавітної заміни (шифру Цезаря)
У шифрі моноалфавітної заміни кожна літера відкритого тексту з числовою позицією m в алфавіті потужності N (де N = 26 для англійського алфавіту та N = 33 для українського алфавіту) циклічно зсувається на фіксоване секретне число K позицій вперед за формулою:
C = (m + K) mod N.
При дешифруванні виконується обернений циклічний зсув на K позицій назад:
m = (C - K) mod N.

Для наочного покрокового відображення роботи алгоритму було розроблено інтерактивний веб-модуль у вкладці «ЛАБ 01 -> 1.1. Шифр Цезаря» та консольний скрипт на мові Python.
Програмна реалізація функції шифрування та дешифрування шифром Цезаря:

```python
UA_ALPHABET = "АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ"
EN_ALPHABET = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

def caesar_cipher(text: str, key: int, decrypt: bool = False) -> str:
    alphabet = EN_ALPHABET if any(c.upper() in EN_ALPHABET for c in text) else UA_ALPHABET
    n = len(alphabet)
    shift = (-key if decrypt else key) % n
    result = []
    for ch in text:
        upper_ch = ch.upper()
        if upper_ch in alphabet:
            idx = alphabet.index(upper_ch)
            new_ch = alphabet[(idx + shift) % n]
            result.append(new_ch.lower() if ch.islower() else new_ch)
        else:
            result.append(ch)
    return "".join(result)
```

2. Реалізація методу частотного криптоаналізу
Криптоаналіз моноалфавітного шифру ґрунтується на зіставленні частоти появи символів у перехопленому шифротексті з еталонними статистичними частотами літер природної мови (в українській мові найчастішою є літера «О» з частотою 0,094 та індексом 18; в англійській мові – літера «E» з частотою 0,127 та індексом 4).

Програмна реалізація автоматичного частотного криптоаналізу:

```python
from collections import Counter

def frequency_attack_ua(ciphertext: str, most_common_lang_char: str = "О"):
    filtered = [c.upper() for c in ciphertext if c.upper() in UA_ALPHABET]
    counts = Counter(filtered)
    most_freq_cipher, freq_val = counts.most_common(1)[0]
    key = (UA_ALPHABET.index(most_freq_cipher) - UA_ALPHABET.index(most_common_lang_char)) % len(UA_ALPHABET)
    decrypted = caesar_cipher(ciphertext, key, decrypt=True)
    return key, most_freq_cipher, freq_val, decrypted
```

3. Реалізація шифру стовпцевої перестановки за ключовим словом
У шифрі перестановки відкритий текст записується по рядках у прямокутну матрицю розмірністю R x C, де C – довжина ключового слова. Стовпці нумеруються відповідно до алфавітного порядку літер ключового слова. Криптограма формується шляхом послідовного виписування символів по стовпцях у порядку зростання їхніх номерів.

Програмна реалізація шифрування та дешифрування методом перестановки:

```python
def columnar_transposition_encrypt(plaintext: str, keyword: str) -> str:
    cols = len(keyword)
    order = sorted(range(cols), key=lambda i: (keyword[i].upper(), i))
    rows = (len(plaintext) + cols - 1) // cols
    padded = plaintext.ljust(rows * cols, " ")
    matrix = [list(padded[r * cols:(r + 1) * cols]) for r in range(rows)]
    return "".join(matrix[r][c] for c in order for r in range(rows))

def columnar_transposition_decrypt(ciphertext: str, keyword: str) -> str:
    cols = len(keyword)
    rows = (len(ciphertext) + cols - 1) // cols
    order = sorted(range(cols), key=lambda i: (keyword[i].upper(), i))
    matrix = [[""] * cols for _ in range(rows)]
    idx = 0
    for c in order:
        for r in range(rows):
            matrix[r][c] = ciphertext[idx] if idx < len(ciphertext) else " "
            idx += 1
    return "".join("".join(row) for row in matrix).rstrip()
```

1. Опишіть алгоритм шифрування Цезаря.
Шифр Цезаря — це симетричний алгоритм моноалфавітної підстановки, в якому кожен символ відкритого тексту замінюється символом, що знаходиться на фіксованій кількості позицій K далі в алфавіті (у класичному варіанті K = 3). Досягнувши кінця алфавіту, відлік циклічно переходить на його початок за правилом модульної арифметики C = (M + K) mod N.
2. У чому суть методу частотного криптоаналізу?
Метод базується на тому, що в будь-якій природній мові окремі літери зустрічаються з відомою середньостатистичною частотою. Оскільки при моноалфавітній заміні однакова літера завжди переходить в один і той самий символ криптограми, криптоаналітик знаходить найчастіший символ у шифротексті, прирівнює його до найчастішої літери мови (наприклад, «О» для української або «E» для англійської) і знаходить ключ K як різницю їхніх індексів в алфавіті.
