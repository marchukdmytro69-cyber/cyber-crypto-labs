Мета роботи – вивчити архітектуру та математичний апарат симетричного блочного шифрування на прикладі спрощеного алгоритму S-DES (Simplified DES), дослідити процедуру розгортання раундових підключів (K1, K2), роботу початкової та оберненої перестановок (IP, IP^-1), нелінійних таблиць заміни (S0, S1) і раундової функції Мейстера-Фейстеля, а також виконати покрокове дешифрування індивідуальної криптограми.

Завдання до роботи:
Використовуючи 10-бітний ключ (0011011101), розшифрувати криптограму свого варіанту, зашифровану алгоритмом S-DES. Продемонструвати проміжні результати, отримані на виході кожної функції (IP, f_K, SW, f_K, IP^-1), та перетворити отриману двійкову послідовність у десяткове число.

- Вхідна 8-бітна криптограма C: 01110011
- 10-бітний ключ K: 0011011101

Хід роботи

1. Покрокова процедура генерування раундових підключів K1 та K2
Вхідний 10-бітний ключ: K = (0011011101).
Крок 1. Застосовуємо перестановку P10 = [3, 5, 2, 7, 4, 10, 1, 9, 8, 6]:
P10(0011011101) = (1001110011).
Крок 2. Розділяємо отриману послідовність на дві 5-бітні половини:
L = 10011, R = 10011.
Виконуємо циклічний зсув ліворуч на 1 позицію (LS-1) для кожної половини окремо:
LS-1(10011) = 00111, LS-1(10011) = 00111 -> об'єднано: (00111 00111).
Крок 3. Застосовуємо перестановку стиснення P8 = [6, 3, 7, 4, 8, 5, 10, 9] для отримання першого підключа K1:
K1 = P8(0011100111) = (01011111).
Крок 4. До половин після першого зсуву (00111 та 00111) застосовуємо циклічний зсув ліворуч на 2 позиції (LS-2):
LS-2(00111) = 11100, LS-2(00111) = 11100 -> об'єднано: (11100 11100).
Крок 5. Застосовуємо перестановку P8 для отримання другого підключа K2:
K2 = P8(1110011100) = (11101000).

Отже, раундові підключі становлять:
K1 = 01011111, K2 = 11101000.
Оскільки виконується розшифрування, у першому раунді f_K використовується підключ K2, а у другому раунді – підключ K1 (рис. 1).

3. Програмна реалізація алгоритму S-DES на мові Python:

```python
P10 = [3, 5, 2, 7, 4, 10, 1, 9, 8, 6]
P8  = [6, 3, 7, 4, 8, 5, 10, 9]
IP  = [2, 6, 3, 1, 4, 8, 5, 7]
IP_INV = [4, 1, 3, 5, 7, 2, 8, 6]
EP  = [4, 1, 2, 3, 2, 3, 4, 1]
P4  = [2, 4, 3, 1]

S0 = [[1, 0, 3, 2], [3, 2, 1, 0], [0, 2, 1, 3], [3, 1, 3, 1]]
S1 = [[1, 1, 2, 3], [2, 0, 1, 3], [3, 0, 1, 0], [2, 1, 0, 3]]

def permute(bits: str, table: list) -> str:
    return "".join(bits[i - 1] for i in table)

def ls(bits: str, n: int) -> str:
    return bits[n:] + bits[:n]

def xor_bits(a: str, b: str) -> str:
    return "".join("0" if x == y else "1" for x, y in zip(a, b))

def sbox_lookup(bits4: str, sbox: list) -> str:
    row = int(bits4[0] + bits4[3], 2)
    col = int(bits4[1] + bits4[2], 2)
    return format(sbox[row][col], "02b")

def generate_subkeys(key10: str):
    p10 = permute(key10, P10)
    l1, r1 = ls(p10[:5], 1), ls(p10[5:], 1)
    k1 = permute(l1 + r1, P8)
    l2, r2 = ls(l1, 2), ls(r1, 2)
    k2 = permute(l2 + r2, P8)
    return k1, k2

def fk(bits8: str, subkey: str) -> str:
    L, R = bits8[:4], bits8[4:]
    xored = xor_bits(permute(R, EP), subkey)
    s_out = sbox_lookup(xored[:4], S0) + sbox_lookup(xored[4:], S1)
    return xor_bits(L, permute(s_out, P4)) + R
```

Відповіді на контрольні запитання:
1. Яку розмірність блоку та ключа використовує алгоритм S-DES і з яких 5 операцій він складається?
Алгоритм S-DES оперує 8-бітними блоками даних та 10-бітним ключем, з якого утворюються два 8-бітні раундові підключі. Шифрування та дешифрування складаються з 5 операцій: 1) початкова перестановка IP; 2) раундова функція f_K; 3) перестановка половин SW; 4) повторне виконання раундової функції f_K; 5) обернена перестановка IP^-1.
2. Як працюють модулі заміни S0 та S1?
Кожна S-матриця приймає на вхід 4 біти: перший і четвертий біти визначають двійковий номер рядка (від 0 до 3), а другий і третій біти – двійковий номер стовпця (від 0 до 3). Елемент на перетині рядка і стовпця подається у вигляді 2-бітної двійкової послідовності.
3. У чому полягає відмінність між шифруванням та розшифруванням у S-DES?
Структура алгоритму залишається повністю ідентичною, проте під час розшифрування раундові підключі подаються у зворотному порядку: у першому виклику f_K використовується K2, а у другому – K1.
