# AEGIS // CRYPTO-OPS TACTICAL TERMINAL

Інтерактивний веб-термінал та набір Python-скриптів для виконання і візуалізації лабораторних робіт з дисципліни **«Прикладна криптологія»** (НУ «Львівська політехніка», кафедра захисту інформації, група КБ-305, Варіант 12 — Марчук Дмитро Андрійович).

## Структура проєкту

- `index.html` — головний тактичний інтерфейс із покроковою візуалізацією алгоритмів для Лабораторних робіт №1–4.
- `messenger.html` — окремий багатовіконний месенджер у реальному часі (Аліса, Перехоплювач MITM, Боб) із синхронізацією через `BroadcastChannel` та `localStorage`.
- `css/styles.css` — стилізація у темно-синій та чорній кібербезпековій палітрі.
- `js/crypto-engines.js` — криптографічні рушії (Цезар, Частотний аналіз, Стовпцева перестановка, SHA-256, HMAC-SHA256, JWT HS256, S-DES, Протокол Діффі-Хеллмана та MITM).
- `js/visualizers.js` — інтерактивні SVG-візуалізатори (кільце Цезаря, гістограма частот, матриці перестановок, S-DES раунди та комутаційні мережі).
- `js/app.js` та `js/lab-content.js` — контролери інтерфейсу, база 25 студентів групи КБ-305, генератор Python-коду та відповіді на контрольні запитання.
- `python_labs/` — автономні консольні та серверні скрипти Python для кожної лабораторної роботи:
  - `lab1_ciphers.py` — Лабораторна робота №1 (Шифр Цезаря, криптоаналіз, стовпцева перестановка).
  - `lab2_jwt_server.py` — Лабораторна робота №2 (Flask REST API сервер із SHA-256 та JWT HS256 на маршрутах `/login` і `/protected`).
  - `lab3_sdes.py` — Лабораторна робота №3 (Блочний шифр S-DES, генерація ключів `K1`, `K2` та розшифрування всіх 25 варіантів).
  - `lab4_diffie_hellman_mitm.py` — Лабораторна робота №4 (Протокол Діффі-Хеллмана та моделювання атаки «Людина посередині»).
- `reports/` — готові звіти у форматах `.docx` та `.md` для всіх 4 лабораторних робіт (`Zvit_Lab_1.docx` – `Zvit_Lab_4.docx`).

## Швидкий запуск веб-інтерфейсу

```bash
python -m http.server 8090
```

Після запуску відкрийте у браузері:
- Головний термінал: `http://localhost:8090`
- Месенджер Аліси: `http://localhost:8090/messenger.html?role=alice`
- Месенджер Перехоплювача (MITM): `http://localhost:8090/messenger.html?role=attacker`
- Месенджер Боба: `http://localhost:8090/messenger.html?role=bob`
